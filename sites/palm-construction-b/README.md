# Palm Construction — redesigned site

Generated by `../build.py`; do not edit the HTML by hand. Change the copy
tables or CONFIG in the script and rerun.

Two pages: `index.html` (home) and `contact.html`. Service, FAQ, careers and
blog links point at the existing pages on palmconstructionwa.com until those
are rebuilt.

## Media provenance

- `assets/hero/lakefront.mp4` — the first 10 s of the live site's hero video
  (`0430.mp4`, the client's own drone reel), re-encoded to 1.9 MB with a
  seamless loop. `lakefront-poster.jpg` is its first frame.
- `assets/hero/sitereel.mp4` — the first 20 s of the client's Sammamish deck
  progress reel from their projects page, with its original audio (the
  project manager speaking; AAC 96k). 5.5 MB, loads only on play.
- `assets/img/*` — stills from the two reels and the client's gallery photos,
  except `dusk-*` and `plans-*`, which are generated atmosphere plates
  (Gemini, `tools/gen-palm-images.py`) used only as backdrops under text,
  and `sound-deck-*`, the background image from the live site.
- `assets/identity/*` — the client's mark, resized; `og.png` is rendered by
  the build.

## Before launch

- Set `quote_endpoint` (JSON POST) or `email` in `build.py` — the live site
  publishes no email, so the form currently tells visitors to call.
- Confirm which phone number is the main line; both are shown.
- Confirm the L&I number against lni.wa.gov and the claims flagged in
  `../REPORT.md` (financing up to 100%, start within a week, TrexPRO tier).
