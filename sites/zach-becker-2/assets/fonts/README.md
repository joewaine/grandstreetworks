# Font provenance

This preview self-hosts two open-source Google Fonts families so it has no runtime font dependency:

- Cormorant Garamond: 500, 500 italic, and 600
- DM Sans: 400, 500, and 600

Source CSS endpoints:

- `https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,500;0,600;1,500&display=swap`
- `https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;600&display=swap`

See the Google Fonts pages for the applicable SIL Open Font License information before redistribution outside this benchmark package.
