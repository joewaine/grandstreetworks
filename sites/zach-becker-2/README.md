# Website redesign preview

A responsive static homepage concept for Zach Becker, built from the supplied assets and an independently created Figma system.

## Preview

From this folder, run:

```sh
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

No build step or third-party runtime dependency is required. The form demonstrates validation, loading, error, and success states locally; secure delivery intentionally requires a production endpoint.

## Key files

- `index.html`, `styles.css`, `script.js` — local static implementation
- `01-audit.md` — source-site audit, facts, assumptions, and opportunity ranking
- `01-creative-strategy.md` — three directions and selected concept
- `01-design-review.md` — adversarial five-perspective design review
- `02-qa-log.md` — viewport captures and correction loops
- `03-canva-notes.md` — Canva rationale and handoff
- `FINAL-REPORT.md` — consolidated delivery report
- `primary-desktop.png`, `primary-mobile.png` — representative screenshots
