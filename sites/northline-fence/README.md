# Northline Fence — client site

A one-page site for a fencing contractor in Washington state. Built from the
Grand Street Works trade set (the roofing and general-contractor builds are
its nearest relatives), but it is a **real client site**, not a reference
build: no `noindex`, no "fictional" footer, and it lives here under `sites/`
rather than `work/` so it can be lifted onto its own domain unchanged.

Generated by `tools/build-fencing-site.py`. **Do not edit `index.html` by
hand** — change `CONFIG` or the copy tables in the script and rerun:

    python3 tools/build-fencing-site.py --page     # rewrite index.html only
    python3 tools/build-fencing-site.py            # also re-encode images, identity

Photographs were generated with `tools/gen-fencing-images.py` (Gemini,
`gemini-3-pro-image`); the 4MB originals sit outside the repo in
`~/fractal/clients/northline-fence/originals` and only the AVIF/JPEG ladder
(3.7MB total) is committed.

## Before this goes live

Everything below is a placeholder and lives in one place, `CONFIG` at the top
of `tools/build-fencing-site.py`:

| Field | Now | Replace with |
|---|---|---|
| `name`, `legal` | Northline Fence | the real business name (nothing by that name exists in WA today, but check again before launch) |
| `phone` | (360) 555-0142 | the owner's number. 555-01xx is reserved for fiction, so the `tel:` links cannot dial anyone until this changes |
| `email` | quotes@northlinefence.com | where the quote form should land |
| `town`, `area_*`, `towns` | Everett / Snohomish & King counties | the real base and service area. The reviews also name towns; see below |
| `lni` | NORTHLFC000AA | the real WA L&I registration number (12 characters, verifiable at lni.wa.gov). Washington requires it on advertising |
| `since`, `hours` | 2016 / Mon–Sat 7–6 | as they are |
| `url` | grandstreetworks.com/sites/northline-fence/ | the final domain, for `og:image` and JSON-LD |

And three things that are not config:

1. **Reviews are invented.** `REVIEWS` in the script has three sample quotes
   with sample names and towns. Replace them with the owner's real Google
   reviews (or delete the section) before launch. Do not ship fabricated
   reviews on a real business.
2. **Photographs are generated.** They are convincing and Washington-specific
   (western red cedar, Douglas fir, overcast), but they are not the owner's
   work. The right move is to swap in real job photos as they come in, one
   at a time, by dropping a JPEG into the originals folder under the same
   name and rerunning the build. The before/after pair in particular should
   become a real one.
3. **The quote form** has no backend. With `quote_endpoint` empty it opens the
   visitor's mail client with the fields filled in (and does the same without
   JavaScript, via `mailto:` + `enctype=text/plain`). Point it at a real
   endpoint — the intake API in `intake-api/` would do with a second route,
   or Formspree/Basin — and the JS posts JSON there instead.

## Hosting

The folder is static and self-contained: `index.html` plus `assets/`. It
already serves from this repo at `/sites/northline-fence/` on Render, which is
fine for showing the owner. For their own domain, either a second static
service on Render pointed at this folder, or copy the folder anywhere that
serves files. One Google Fonts request (Barlow, Barlow Condensed) is the only
external dependency.
