# SoHo Men's Health homepage redesign

This is a dependency-free static implementation of the selected “Care Ledger” direction.

## Local preview

From this directory:

```sh
python3 -m http.server 4397 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4397/`.

Appointment, service, quiz, patient portal, price, social, review, and directions links intentionally continue to the existing published destinations. The live site is not modified and the project is not deployed.
